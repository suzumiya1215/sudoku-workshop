# 数独工坊

单文件数独应用：13 种玩法、SE 十级难度、A4 练习册打印、手机可用。
双击 `数独工坊.html` 即可运行，不需要服务器、不联网、没有外部依赖。

- **在线版**：<https://suzumiya1215.github.io/sudoku-workshop/> —— 手机浏览器打开即玩，免下载
- **仓库**：<https://github.com/suzumiya1215/sudoku-workshop>

## 特性

**出题与评级**

- 13 种玩法：经典、对角线、反骑士、反王、锯齿、杀手、温度计、箭头、三明治、小杀手、连续、耳语、混合变种。
- 难度按 SE（Sudoku Explainer Rating）分十档，每档卡在一个具体技巧台阶上：L1 极简 → L10 大师。
- 界面显示「评级依据」：本题共 N 步、最难一步用了什么技巧（SE x.x），档位由步骤反推得出，不是先定档位再套步骤。
- 18 种人类解题技巧的完整实现与逐步求解路径，可用于提示、演示、专项训练。

**做题**

- 键盘全通：`1–9` 填数、`Shift+1–9` 记候选、`0`/`Delete`/`Backspace` 清除、方向键移动、`N` 笔记、`U`/`Ctrl+Z` 撤销、空格暂停。
- 棋盘四边带 `R1–R9` / `C1–C9` 坐标，可直接对照「R8C3」定位。
- 同数高亮、冲突标红、候选数显示、撤销栈（200 步）、计时暂停。
- 逐步演示可随时停止、可单步前进。

**打印**

- 三种版式：1 题/页、2 题/页（含技巧清单 + 演算区）、4 题/页（含草稿区）。
- A4 竖版、纯矢量、内嵌字体，参考答案单独成页。
- 网格线由 SVG 一次画完（打印 0.9pt 细线 / 1.8pt 宫线），保证每格框线粗细一致、不缺线。

**手机**

- 棋盘按屏宽自适应，数字盘 5 列大按钮，标签栏横向滚动，表格列宽按百分比。
- 实测 390 / 412 / 768px 三种宽度无横向滚动。

## 快速开始

```bash
# 直接打开
数独工坊.html

# 从源码重新构建
python build.py
```

源文件在 `src/`，`build.py` 把 CSS 与 JS 内联进 `template.html`，产出根目录的 `数独工坊.html`。

## 测试

回归脚本用 `puppeteer-core` 驱动本机 Edge（Windows）。


最近一次全量结果：156 道技巧路径校验错误 0；三版式棋盘 580 / 329 / 301px 无越界；50 题 39 页 A4。

## 已知限制

- **SE 是离散值**：一个技巧等级差 0.4 分，L6–L9 区间窄，批量出题时常落到相邻档（50 题里约 15–17 道偏差，最坏 L9→L4）。结果文案会如实标注 `L5→L4 ×2` 这样的映射。
- **杀手/混合有 2.4 底分**：笼和推理在候选数剪枝里被当成免费计算，路径 SE 会显示为 1.2，因此设有底分。代价是这两类玩法最高只能出到 L3。
- **变种难度不能只看 SE**：笼和、温度计、箭头等变种约束没有单独计分，SE 只反映路径上的技巧，不反映变种本身的认知负担。
